## Core Packages

| Package | What it provides | Install | Resources |
| --- | --- | --- | --- |
| **capsolver-core** | Python SDK for scripts, crawlers, and browser automation | `pip install capsolver-core` | [PyPI](https://pypi.org/project/capsolver-core/) · [GitHub](https://github.com/capsolver-ai/capsolver-core) · [Docs](https://docs.capsolver.com/en/guide/ai/core-sdk/) |
| **capsolver-agent** | CapSolver tools for AI agents and automation frameworks | `pip install capsolver-agent` | [PyPI](https://pypi.org/project/capsolver-agent/) · [GitHub](https://github.com/capsolver-ai/capsolver-agent) · [Docs](https://docs.capsolver.com/en/guide/ai/agent-tools/) |
| **capsolver-mcp** | MCP server for compatible AI assistants and development tools | `pip install capsolver-mcp` | [PyPI](https://pypi.org/project/capsolver-mcp/) · [GitHub](https://github.com/capsolver-ai/capsolver-mcp) · [Docs](https://docs.capsolver.com/en/guide/ai/mcp-service/) |
